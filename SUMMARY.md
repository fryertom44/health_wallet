## Data Flow

1. User uploads file → Controller saves to AssessmentImport
2. Controller broadcasts "pending" status → Job enqueues
3. Job processes file → Creates/updates records
4. Job broadcasts success/error → Real-time UI update
5. Job cleans up temporary file → Process complete

The implementation provides a robust, user-friendly assessment import system with comprehensive error handling and real-time feedback.
